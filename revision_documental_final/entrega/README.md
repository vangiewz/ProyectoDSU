## Conservación del documento

El Word editable y PDF vigente se conservan sin reensamblar. Los generadores académicos y las versiones anteriores quedaron fuera de GitHub por decisión del titular; sus antecedentes siguen disponibles en el respaldo privado local. Los modelos nativos, figuras, matrices y evidencias sí forman parte de esta entrega.

Para las evidencias audiovisuales descargadas de GitHub, entrar a evidencias/Evidencias_GUI_DSU_Residata.zip.partes y ejecutar python reconstruir.py. Se verifica SHA-256; el ZIP original local se conserva. Todas las partes son necesarias.

Las pruebas de software completas se reproducen con el runner aislado del repositorio, no lanzando los tests incluidos contra el entorno compartido. Las credenciales no forman parte de esta entrega. La configuración de publicación se documenta en despliegue/vercel_proyectos.json. Los accesos privados corresponden al titular.
