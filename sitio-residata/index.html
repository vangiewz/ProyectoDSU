Residata es la plataforma boliviana para gestionar la recolección de residuos sólidos. El personal registra el peso desde el teléfono, el supervisor planifica rutas y cuadrillas, y un modelo Random Forest anticipa cuántos kilos generará cada punto.

Instrucciones al dorso del comprobante

  1. Se pesa y registra

    El operario elige el punto y el tipo de residuo y anota los kilos desde el teléfono, con hora y autor.

  2. Se depura

    El proceso ETL de cada hora valida unidades, descarta duplicados y marca valores atípicos para revisión.

  3. Se entrena

    Un Random Forest Regressor aprende por punto, tipo, día, semana y periodo académico.

  4. Se proyecta

    Cada estimación sale con su margen de error y la versión del modelo que la produjo.

  5. Se decide

    Las alertas de desborde y las recomendaciones llegan al supervisor, que decide y deja constancia.
